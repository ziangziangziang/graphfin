# GraphFin 0.1.0-alpha — draft

This alpha brings the multi-graph performance and native time-series work streams
together in a general-purpose graph database derived from TuGraph 4.5.2. It is
intended for evaluation of the explicitly qualified feature set.

## Included work

- Vertex and edge time-series fields with typed measures, point/range reads,
  updates, value-based compare-and-set and aggregates.
- Lazy graph loading, bounded open-graph admission and eviction infrastructure.
- Existing HA replication implementation and dedicated merged-series tests.
- Whole-graph placement/routing/fencing/migration-state components, with the
  unfinished data-plane integration identified as experimental.
- English and Chinese product READMEs, a combined roadmap, generated feature
  artwork, and a merge qualification plan using finance and telemetry fixtures.

## Compatibility and known limits

Product version 0.1.0-alpha is separate from the inherited engine compatibility
version 4.5.2. Legacy executable and API names remain. There is no claim of an
upstream-to-fork in-place upgrade, downgrade or mixed-version HA support until the
corresponding fixture/restore tests pass.

Series currently hold one mutable point per timestamp. Historical revisions,
knowledge-time context, bounded cursors and native batch import remain planned.
New non-finite DOUBLE writes are rejected; previously stored non-finite observations
need an explicit export/migration policy. Value-based CAS is not request deduplication.
Live shard forwarding, server fence integration and migration data movement are
not completed features.
